# SI / VGM Builder

เครื่องมือสร้างไฟล์ SI / VGM (Excel) จาก Booking Request — **ไฟล์เดียว `SI_VGM_Tool.html`**
ดับเบิลคลิกเปิดใน Chrome / Edge ได้ทุกเครื่อง ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต ข้อมูลไม่ออกนอกเครื่อง

## วิธีใช้
หน้าจอแบ่ง 2 ฝั่ง: ซ้ายคือฟอร์ม, ขวาคือ **Preview ไฟล์ Excel จริง** (สลับดูชีต SI DATA / VGM / ATTACH ได้, กรอบสีน้ำเงิน = ช่องที่เครื่องมือกรอก, กรอบส้ม = ยังรอข้อมูล)

1. เปิด `SI_VGM_Tool_SRAU.html` (มี Template ในตัว) หรือ `SI_VGM_Tool.html` (ต้องวาง Template เอง)
2. ลาก **Booking Request** มาวาง — ข้อมูล Shipment / Pieces / kg / CBM เข้าเอง
   - วาง **PDF ใบยืนยัน Booking ของ Shinki** (`SE…pdf`) และ **C Invoice PDF** ด้วย เพื่อตรวจเทียบ (ลากไฟล์แนบจากเมลมาทั้งหมดได้ ไฟล์ที่ไม่ใช้ เช่น P invoice / .csv / .xls จะถูกข้าม)
3. ทีมตู้กรอกเลขตู้ / ซีล / Tare ลง **Booking Request ไฟล์เดิม** ในคอลัมน์ที่เพิ่มต่อท้ายตารางตู้ (หัวตาราง `CONTAINER` · `Seal No.` · `Tare kg` แถวเดียวกับตู้แต่ละใบ)
4. ลากไฟล์ Booking ที่ทีมกรอกแล้วมาวางซ้ำ → เครื่องมือเติมเลขตู้/ซีล/Tare ให้ โดยไม่ล้าง PDF หรือข้อมูลที่ทำไว้ (กรอกมาไม่ครบก็ได้ วางใหม่ได้เรื่อย ๆ) · พิมพ์ในตารางตู้เองก็ได้
5. ดูแถบตรวจสอบ แล้วกด **ดาวน์โหลด SI / VGM**
6. ไฟล์ติดตามงาน **Report_Shipment Export** (แบบพื้นฐาน):
   - งานใหม่: ใส่ JOB No. → กด **คัดลอกแถวลง Report** → คลิกช่อง A ของแถวว่างแรกใน Report → Ctrl+V (ได้คอลัมน์ A–X 1 แถวต่อตู้ ในรูปแบบเดียวกับที่ทีมกรอก: 40DC, ชื่อเมือง, วันที่ cut off จาก PDF Shinki)
   - ทีมตู้ส่งข้อมูลแล้ว: กด **คัดลอกเฉพาะ Container + Seal** → คลิกช่อง O ของแถวตู้แรกของงานนั้น → Ctrl+V
   - (ตัวเลือก ปิดไว้เป็นค่าเริ่มต้น) ติ๊ก **ใช้ Power Automate** ถ้าตั้ง Flow แล้ว — วิธีตั้งค่าดู [`power-automate/README.md`](power-automate/README.md)

## บันทึกงาน / ดูงานที่ทำไปแล้ว
- ปุ่ม **บันทึกงาน** (ข้อ 4) — และบันทึกให้เองตอนดาวน์โหลด SI / คัดลอกลง Report
- ปุ่ม **งานที่บันทึกไว้ (n)** มุมบนขวา: รายการ Booking ทั้งหมด พร้อมสถานะ (ตู้/ซีล x/y, Tare x/y, PDF, ดาวน์โหลด SI เมื่อไหร่, ลง Report แล้วหรือยัง) · ค้นหา · **เปิด** เพื่อทำต่อ (ข้อมูลตู้, PDF, ช่องที่แก้ไว้กลับมาครบ) · ลบ
- วาง Booking ที่เคยบันทึกไว้ซ้ำ เครื่องมือจะถามว่าจะเปิดงานเดิมทำต่อไหม
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (ไม่ได้อยู่ในตัวไฟล์ .html) — ถ้าล้างข้อมูลเบราว์เซอร์ เปลี่ยนเครื่อง หรือเปลี่ยนจาก Chrome เป็น Edge จะไม่เห็น · กด **ส่งออกไฟล์สำรอง** เก็บไว้ (เช่นใน OneDrive) แล้ว **นำเข้าไฟล์สำรอง** ในเครื่อง/เบราว์เซอร์อื่นได้

## สิ่งที่เครื่องมือกรอกให้
| ชีต | ช่อง |
|---|---|
| SI DATA | Booking (J2), เรือ/เที่ยว (A28), POL (D25/D28), POD/Place of delivery (A31/D31), จำนวนตู้ (D38), Pieces/KGS/CBM (D39/J39/K39), Description (E40), I/V No. (E41), TOTAL … CONTAINER(S) (C58), Consignee (A9–A12), Notify (A17–A20), Agent (G24–G27) |
| ATTACH SHEET | แถว 6–20: เลขตู้, ซีล, Pieces, KGS, CBM, Type — แถวที่ไม่ใช้ถูกล้าง |
| VGM | แถว 12–26: วันชั่ง, Method 2, Tare — เลขตู้/น้ำหนัก/Total VGM เป็นสูตรเดิมของ template |

รูปแบบ, merge, สูตร ของ template คงเดิมทั้งหมด (แก้เฉพาะค่าใน cell) และ Excel จะคำนวณสูตรใหม่เมื่อเปิดไฟล์

## การตรวจสอบ
- เลขตู้ ISO 6346 (รูปแบบ + check digit), เลขตู้ซ้ำ, ช่องว่าง
- ผลรวม Pieces / kg / CBM เทียบ Booking, จำนวนตู้เทียบ Booking
- วันชั่งเลย CY Cut / เลย VGM cut off ใน PDF Shinki
- Tare และวันชั่ง (ชีต VGM) ที่ยังไม่รู้ ปล่อยว่าง (ไม่ใส่ค่าเดา) จนกว่าทีมตู้จะส่ง Tare จริง
- **เทียบกับ PDF ใบยืนยัน Shinki** (อ่านด้วย OCR ในเครื่อง ใช้เวลา ~3–5 วินาที): Booking No., จำนวน/ขนาดตู้, ETD, ETA, POL, POD, Place of delivery, เรือ/Voyage, Carrier, Closing date/time เทียบ CY Cut
- **เทียบกับ C Invoice PDF**: Invoice No., เรือ/Voyage, Shipping line, To Port, Destination (ถ้ามีรัฐ ต้องตรงด้วย), Sailing/ETD, ETA, จำนวนตู้, Pieces รวม

## สำหรับผู้พัฒนา
แก้โค้ดที่ `src/app.html` แล้วรัน `python3 build.py` เพื่อรวมไลบรารีใน `vendor/` (JSZip, PDF.js, Tesseract OCR + ภาษาอังกฤษ) เข้าเป็น `SI_VGM_Tool.html` ไฟล์เดียว (~6.6 MB) — ตัวอ่าน PDF / OCR ถูกเก็บแบบบีบอัดและแตกออกเฉพาะตอนวาง PDF

## ทำ Template เปล่าจากไฟล์ที่กรอกแล้ว
```
python3 make_blank_template.py ไฟล์ที่กรอกแล้ว.xlsx Template_เปล่า.xlsx
```
ล้างข้อมูลงาน (Booking, เรือ, ท่าเรือ, จำนวนตู้/น้ำหนัก, I/V, รายการตู้, ข้อมูล VGM) แต่คงข้อมูลคงที่ (Shipper, Consignee, Notify, Agent, ผู้ติดต่อ, FREIGHT PREPAID) และรูปแบบ/สูตรไว้

## ตรวจว่าไฟล์ที่ได้ไม่เพี้ยนจาก Template
```
python3 audit_xlsx.py Template.xlsx ไฟล์ที่ได้.xlsx
```
เทียบทีละช่อง: style/ฟอนต์, merge, ความกว้างคอลัมน์, ความสูงแถว, ตั้งค่าหน้ากระดาษ, สูตร และแสดงรายการข้อความที่เปลี่ยน
