## 🛠️ ทำตอนใหม่
ใช้ skill `thai-horror-shorts` ที่ [`.claude/skills/thai-horror-shorts/SKILL.md`](.claude/skills/thai-horror-shorts/SKILL.md)
ถ้าเปิด repo นี้กับ Claude Code แล้วพิมพ์ว่า "ทำ EP7 …" Claude จะใช้ skill นี้ให้อัตโนมัติ

```bash
cd .claude/skills/thai-horror-shorts
cp -r examples/ep6 /tmp/ep7                          # เริ่มจากตัวอย่าง แล้วแก้ script.py + scenes.js
engine/build.sh /tmp/ep7 x.mp4 preview 5,20,40       # ดูภาพตัวอย่างก่อน
engine/build.sh /tmp/ep7 school_ep7.mp4              # เรนเดอร์เต็มเรื่อง
```

**สิ่งที่ต้องมี:** ffmpeg, Python + numpy, Node + Playwright, `pip install edge-tts`
**เครือข่าย:** ต้องอนุญาตเว็บ `speech.platform.bing.com` ในการตั้งค่าเครือข่ายของ environment
