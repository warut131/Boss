# Prompt ทำคลิปผี 3D "หลอนก่อนนอน" ไปใช้ต่อที่อื่น

ไฟล์นี้มี prompt พร้อมคัดลอก ใช้กับ Claude ที่อื่นได้ เช่น session ใหม่ใน Claude Code, claude.ai หรือเครื่องของคุณเอง แล้วจะได้คลิปสไตล์เดียวกับ **"เทเกะ เทเกะ" (3D)**

## 0) เตรียมก่อนใช้

| สิ่งที่ต้องมี | หมายเหตุ |
|---|---|
| ไฟล์ skill `thai-horror-shorts.skill` | แตกไฟล์ไว้ที่ `.claude/skills/thai-horror-shorts/` ใน repo หรืออัปโหลดเข้า claude.ai ที่ Settings → Capabilities → Skills |
| ffmpeg, Python 3 + numpy, Node + Playwright (Chromium) | ต้องติดตั้งเอง |
| `pip install edge-tts` | ใช้ทำเสียงพากย์ไทย |
| อนุญาตเว็บ `speech.platform.bing.com` | ถ้าใช้ Claude Code บนคลาวด์ ตั้งค่าที่ Environment → Network access → Allowed domains |
| Three.js | **ไม่ต้องติดตั้ง** มีอยู่ใน skill แล้วที่ `engine3d/three/` |

> ⚠️ claude.ai แบบแชตธรรมดารันโปรแกรมเหล่านี้ไม่ได้ ให้ใช้ **Claude Code** (บนเว็บ/คลาวด์ หรือบนเครื่องคุณเอง) จะได้ผลที่สุด

## 1) Prompt หลัก: ทำคลิปผี 3D เรื่องใหม่ (คัดลอกทั้งกล่อง)

```
ใช้ skill thai-horror-shorts ทำคลิปเล่าเรื่องผีแบบ 3D (ส่วน "3D style (Three.js)" ใน SKILL.md)
เริ่มจากตัวอย่าง examples/teke3d/

เรื่อง: [ใส่ชื่อเรื่อง หรือเขียนว่า "คิดเรื่องใหม่ให้"]
แนว: หลอน ตื่นเต้น น่าติดตาม จบในตอนเดียว หักมุมตอนจบ

ข้อกำหนด:
- คลิปแนวตั้ง 9:16 (720x1280) ยาว 50–65 วินาที, 12–15 ฉาก
- เล่าเรื่องด้วยบุรุษที่สอง "คุณ…" ประโยคสั้น ฉากละหนึ่งจังหวะ
- เสียงพากย์ไทย th-TH-NiwatNeural (ช้าลง 10%) เสียงผีใช้สไตล์ x/v/c ตามความเหมาะสม
- ซับไทย ขาว/เหลือง/กรอบแดง เน้นคำที่น่ากลัว
- กราฟิก 3D สไตล์ toy/diorama: แสงไฟถนนมีเงา, หมอก, กล้องเคลื่อนแบบหนัง,
  ตัวละครแบบตุ๊กตาน่ารักแต่ผีน่ากลัว, มีไฟส่องตามกล้อง (fill) ให้เห็นหน้าชัด
- ช่วงลุ้นที่สุดให้เพลงเงียบ เหลือแต่เสียงหัวใจ ฉากสุดท้ายแฟลชขาวแล้วตัดจอดำ
- การ์ดตอนจบ: "ตอนต่อไป" + "อย่าลืมกดติดตาม หลอนก่อนนอน" พร้อมเสียงพากย์
- ห้ามใส่เลข EP

ขั้นตอน:
1) เขียนบทเป็นตารางฉาก (ฉาก → คำพากย์ → ภาพ) ให้ฉันดูก่อนสั้นๆ แล้วทำต่อได้เลย
2) สร้าง script.py → รัน engine/gen_ep.py, engine/gen_music.py, engine/mix_ep.py
3) เขียน scene3d.html (ฉาก 3D, ตัวละคร, กล้องต่อฉาก)
4) preview ภาพกลางทุกฉากด้วย engine3d/render3d.js แล้ว "ดูภาพจริง" แก้จุดมืด/บังหน้า/ซับทับ
5) เรนเดอร์ video 30fps (รันพื้นหลัง รอด้วย PID ไม่ใช่ pgrep -f) แล้วรวมเสียงด้วย ffmpeg
6) ทำหน้าปกด้วย engine3d/cover3d.js
7) ส่งคลิป + หน้าปก + ชื่อคลิป + แคปชัน + แท็ก 5 อัน:
   #เรื่องผี #หลอนก่อนนอน #การ์ตูนผี #ขนลุก #fyp  (เรื่องญี่ปุ่นใช้ #ผีญี่ปุ่น แทน #การ์ตูนผี)
```

## 5) ข้อควรรู้จากที่ทำมาแล้ว
- **เรนเดอร์ 3D ช้า:** เครื่องที่ไม่มีการ์ดจอใช้เวลาประมาณ 25–30 นาทีต่อคลิป 60 วินาที ถ้าเครื่องมีการ์ดจอจะเร็วขึ้นมาก
- **ตัวละครหน้ามืด:** ต้องมีไฟส่องตามกล้อง (`fill`) ผมใช้ครึ่งทรงกลมด้านบนเท่านั้น ไม่งั้นจะบังหน้า
- **ผีครึ่งตัวที่นอนคว่ำ:** ใช้ `look(1)` เพื่อให้หน้าหันมาข้างหน้า
- **รอเรนเดอร์:** ให้รอด้วยเลข PID (`kill -0`) อย่าใช้ `pgrep -f` เพราะคำสั่งรอจะเจอชื่อตัวเองแล้ววนไม่จบ
- **เสียงพากย์ (edge-tts):** บางครั้งส่งไฟล์ว่างหรือไฟล์ขาดกลับมา `gen_ep.py` จะลองใหม่ให้อัตโนมัติ 15 ครั้ง
- **ดูภาพก่อนเรนเดอร์เสมอ:** ปัญหาที่เจอบ่อยคือ ซับทับข้อความในภาพ ผีกลืนไปกับพื้นหลังมืด และหน้าตัวละครหันผิดทาง
